# Yunwuxin Portfolio · 3D 工作室

浏览相框、工作室月历、桌上的项目册和视觉方向草稿。点击桌面物件靠近查看，方向键翻页，Esc 返回。夜景与音乐在首次使用时加载。

## 本地运行

使用 Node.js 22.12 或更新版本，在本目录执行 `npm ci`、`npm run dev`。`npm run build` 生成可放在子目录中的静态站点，`npm run preview` 可预览构建结果。
